# Siberi.AI — Changelog

## Session 2026-05-21

### MarkdownText — универсальный препроцессор (`MarkdownText.jsx`)
- Добавлен `preprocessMarkdown()` — двухпроходная нормализация нестандартного AI-форматирования:
  - **Pass 1**: `🔹 1. Заголовок` → `## 1. Заголовок`; `📌 Подзаголовок` → `### Подзаголовок`; `Консультации:` → `**Консультации:**`
  - **Pass 2**: orphan-параграфы после sub-заголовков (`**X:**`, `###`) автоматически превращаются в `- bullet`
- Препроцессор применяется ко всем текстовым сегментам (не трогает code-блоки)
- Исправлена проблема: ответы ботов с emoji-маркерами теперь рендерятся структурированно во всех чатах

### Стили Markdown — блокквоты и bullet акценты
- **ChatPage.css**: добавлен `.md-blockquote` (был полностью отсутствует); bullet акцент `::marker` фиолетовый для AI-пузыря; `##` заголовки с нижней линией; `###` в пурпурном тоне
- **ChatEmbed.css**: те же улучшения для мини-чата и embedded chat

### BotStudio — полноценный Markdown рендер
- Telegram-симулятор (левая панель): bot-ответы теперь через `<MarkdownText>` вместо голого текста
- AI-чат (правая панель): то же самое
- **BotStudio.css**: `counter-reset`, убран `white-space: pre-wrap` для bot-пузырей, добавлено `.md-ol + .md-p` вдавливание

### Demo-чат на лендинге — рефакторинг рендера
- Удалены `plainToMarkdown` и `fixFishka` (вызывали превращение погодных данных в заголовки)
- Добавлен `extractFishka()` — вырезает "Фишка:" из ответа, скрывает слово, рендерит текст как `<div class="demo-fishka">` (голубая карточка)
- `MarkdownText` теперь без `isAi` (светлый пузырь), используются глобальные light-theme стили
- Добавлено `.demo-chat-bubble--ai .md-ol + .md-p` для вдавленных описаний

### Системный промт демо (`AiService.js`)
- Переструктурирован `demoSystemPrompt`: роль/контекст в начале, **форматирование в самом конце** прямо перед вопросом → LLM следует правилам форматирования гораздо лучше
- Убраны тяжёлые markdown-секции из контекста (были шаблоном для копирования)

### Микрофон — накопительный режим (все чаты)
