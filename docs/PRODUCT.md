## 1. ОБЗОР ПРОДУКТА

### Что такое Siberi.AI

**Siberi.AI** — это SaaS-платформа для создания, настройки и деплоя персональных AI-ассистентов, интегрированных с собственными данными пользователя. Это не просто обёртка над ChatGPT — это полноценная инфраструктура искусственного интеллекта как услуга.

**Главная идея:** любой человек или бизнес может за 5 минут получить своего AI-ассистента, который знает именно его данные, работает по его правилам, доступен 24/7 в любом удобном канале (Telegram, VK, сайт, API), умеет читать и **писать** в базу данных — и при этом не требует программирования.

### Ключевые отличия от конкурентов

## 2. ДЛЯ КОГО И ЗАЧЕМ

### 2.1 Предприниматель / малый бизнес

**Боль:** операторы поддержки дорого стоят, работают не 24/7, делают ошибки и увольняются. Обычные чат-боты по скриптам неудобны, клиенты их ненавидят.

**Решение Siberi.AI:**
- Загружаете прайс-лист, расписание, FAQ, каталог — AI моментально их знает
- AI отвечает клиентам в Telegram или на сайте 24/7, точно и вежливо
- Принимает заявки, записывает клиентов прямо в базу данных
- Администратор видит историю всех диалогов и данные через панель управления

**Примеры:**
- Барбершоп: запись на стрижку через Telegram-бот без оператора
- Интернет-магазин: консультант по каталогу, проверка наличия, оформление заявки
- Медицинская клиника: запись на приём, ответы на вопросы по услугам
- Ресторан: меню, бронирование столиков, спецпредложения

### 2.2 Разработчик / технический специалист

**Боль:** интеграция AI в свои проекты требует месяцев разработки, настройки инфраструктуры, безопасности и обслуживания.

**Решение Siberi.AI:**
- Персональный REST API-ключ — подключай к любому проекту
- Готовые шаблоны кода: Telegram-бот, VK-бот, виджет на сайт
- Асинхронная архитектура: `POST /analyze` → `taskId` → `GET /result/:taskId`
- Управление данными через AI-команды (`DB_COMMAND` JSON) — no SQL, no migrations
- Несколько AI-профилей для разных проектов в рамках одного аккаунта
- Webhook-коллбэки для получения результатов на свой сервер
- JavaScript SDK для браузера и Node.js

### 2.3 ИП / мастер / самозанятый

**Боль:** нет времени и знаний для автоматизации. Всё сохраняется в заметках, таблицах или в голове.

**Решение Siberi.AI:**
- База клиентов, записей, расписания — всё в одном месте
- AI сам структурирует данные: «Добавь клиента Иванова на пятницу в 14:00» — и готово
- Можно дать доступ помощнику или администратору с ограниченными правами
- Работает с телефона без установки приложений

### 2.4 Корпоративный пользователь / HR / внутренние инструменты

**Боль:** внутренние базы знаний неудобны, поиск по регламентам занимает часы.

**Решение Siberi.AI:**
- Загрузите все внутренние регламенты, инструкции, FAQ
- Сотрудники спрашивают в обычном чате — AI находит ответ за секунды
- Управление ролями: кто что может спрашивать и делать
- Изолированное хранение данных — не обучает публичные модели

### 2.5 Создатель собственного SaaS на базе Siberi.AI

**Боль:** хочется запустить свой AI-сервис, но инфраструктура стоит дорого.

**Решение:** используй Siberi.AI как backend — бери API-ключ, строй собственный UI. Вся сложность (обработка задач, хранение данных, интеграции) уже решена.

## 3. ПОЛНЫЙ КАТАЛОГ ФУНКЦИЙ

### 3.1 AI-профили (мультиагентность)

Каждый пользователь может иметь несколько **AI-профилей** — независимых конфигураций:
- Собственный системный промпт (характер, задачи, ограничения)
- Собственная база данных и схемы
- Собственные интеграции (разные Telegram-боты → разные профили)
- Цветовые метки для визуальной навигации
- Лимиты профилей по тарифному плану

### 3.2 Интеграции

| Канал | Тип | Статус |
|---|---|---|
| Telegram Bot | Hosted (без сервера) | ✅ Production |
| VK Bot (Callback API) | Hosted (без сервера) | ✅ Production |
| MAX Bot | Hosted (без сервера) | 🔜 Скоро |
| Онлайн-консультант (виджет) | 1 строка кода | ✅ Production |
| Страница AI-чата (fullpage/iframe) | Ссылка | ✅ Production |
| REST API | Bearer Auth | ✅ Production |
| JavaScript SDK | CDN / npm-like | ✅ Production |
| Webhook-коллбэки | Push результатов | ✅ Production |
| Telegram Bot (самостоятельный) | Код-шаблон Node.js | ✅ Production |
| VK Bot Long Poll | Код-шаблон Node.js | ✅ Production |
| MAX Bot Long Poll | Код-шаблон Node.js | 🔜 Скоро |
| Авто-деплой Linux/Mac | bash-скрипт | ✅ Production |
| Авто-деплой Windows | PowerShell | ✅ Production |

**Embed-безопасность:** для виджетов и страниц используются одноразовые embed-токены (30 дней) вместо основного API-ключа. API-ключ никогда не попадает в публичный код.

### 3.3 База данных и схемы данных

- **Записи (Records):** произвольные JSON-объекты, привязанные к профилю
- **Схемы (Schemas):** определяют поля, типы и видимость; AI строго следует им
- **Управление через промт:** напишите AI «Создай схему заявок с полями клиент, товар, сумма, дата» — схема создаётся автоматически через `DB_COMMAND`
- **CRUD через чат:** AI может создавать, редактировать и удалять записи прямо из диалога
- **Rollback:** каждое изменение данных через AI сохраняется как снапшот → одна кнопка отменяет все изменения начиная с любой точки
- **Относительные даты:** AI автоматически преобразует «Завтра», «Вчера», «Послезавтра» в реальные даты перед сохранением
- **Видимость полей:** управляет тем, какие поля AI включает в контекст ответа

**Поддерживаемые типы полей:** text, number, date, url, image, select, boolean

### 3.4 Управление доступом

Трёхуровневая ролевая модель для каждой платформы:

- **Creator (создатель):** полный доступ ко всему, включая управление данными и командами AI
- **Admin (администратор):** расширенные права — настраиваются создателем
- **User (обычный пользователь):** базовые права, анти-абьюз фильтр активен

Настраивается по **платформам** (Telegram, VK, Web, API) и **Platform User ID**. Например: пользователь `telegramId:123456` получает роль `admin`.

**Права администраторов (настраиваются):**
- Управление данными (создание/редактирование/удаление записей)
- Доступ к базе знаний
- Просмотр данных
- Управление схемами
- Создание новых схем
- Персональный режим (история только для конкретного пользователя)

**Права пользователей (настраиваются):**
- Чтение данных
- Запись данных
- Удаление данных

**Блокировка:** владелец может заблокировать любого конечного пользователя по платформе + ID. Блокировки применяются мгновенно.

### 3.5 Bot Studio

Визуальный настройщик AI-ботов с превью Telegram-интерфейса:
- Описание бота (что умеет, для чего)
- Загрузка аватара бота
- Запись приветственного аудиосообщения (микрофон или файл)
- Голосовой тест-чат с ботом прямо в студии
- Превью в стиле реального Telegram-диалога
- Доступен только для планов Pro, Premium и Trial

### 3.6 Управление ИИ (панель «Управление ИИ»)

Полная история запросов всех конечных пользователей:
- Фильтрация по платформе, профилю
- Отображение промпта, ответа, вложений
- Кнопка «Откатить» для отмены изменений данных
- Вкладка «Пользователи» — уникальные пользователи по платформам (без Bot Studio)
- Вкладка «Заблокированные» — список блокировок
- Статистика: всего запросов, уникальных пользователей, заблокированных

### 3.7 Внутренний чат (ChatPage)

Личный чат пользователя с его AI:
- Markdown-рендеринг ответов
- Загрузка изображений (drag&drop, paste, кнопка)
- Голосовой ввод (Web Speech API, русский)
- История сообщений
- Плавающая кнопка чата на всех страницах приложения
- Предзаполнение промпта из Landing page

### 3.8 Данные (MyDataPage)

Таблица и визуальный вид всех записей:
- Фильтрация по профилю и схеме
- Кликабельные URL и изображения в ячейках
- Редактирование записей через форму
- Импорт/экспорт данных

### 3.9 Голосовые функции

- Голосовой ввод в ChatPage, ChatEmbed, Landing, Bot Studio
- Запись приветственного аудио в Bot Studio
- Отправка аудио через Telegram-бот (AI воспринимает голосовые сообщения)
- Отправка изображений через Telegram (AI анализирует картинки)

### 3.10 Партнёрская программа

- Уникальная реферальная ссылка для каждого пользователя
- Вознаграждение: при оплате приглашённым — равнозначный бонус реферреру (отложенный)
- Бонус активируется после окончания текущей подписки
- Список рефералов, статусы, история выплат
- Запрос на вывод вознаграждения

### 3.11 Демо-режим

- Незарегистрированные посетители могут протестировать AI прямо на лендинге
- Диалог с лимитированным числом сообщений
- История демо-сессии сохраняется в localStorage
- Отдельный демо-пользователь с собственным системным промптом

### 4.2 Архитектурные паттерны

**Асинхронная обработка задач:**
```
Client → POST /api/v1/analyze → { taskId }
Client → GET /api/v1/result/:taskId (polling)
Worker → processTask(task) → task.status = 'completed'
```

**DB_COMMAND (AI → база данных):**
AI возвращает в ответе JSON-объект `DB_COMMAND` для операций с данными:
```json
{"action":"create","schema":"заявки","data":{"клиент":"Иван","сумма":5000,"дата":"19.05.2026"}}
{"action":"update","schema":"клиенты","recordId":"...","fields":{"статус":"Оплачен"}}
{"action":"delete","schema":"товары","recordId":"..."}
{"action":"create_schema","name":"расписание","fields":[{"name":"дата","type":"date"},{"name":"клиент","type":"text"}]}
```

**Снапшоты для rollback:**
Каждый DB_COMMAND сохраняет `UserRecordSnapshot` с полным документом до изменения → атомарный откат через MongoDB.

**Многоплатформенная идентификация:**
```
endUser: { platform: 'telegram'|'vk'|'max'|'web'|'api'|'studio', platformUserId: string }
```
По этому ключу определяется роль (creator/admin/user) через `UserPermissions`.

**Embed-токены:**
Короткоживущие токены (30 дней) для виджетов и fullpage чатов. `checkAccess` middleware поддерживает как API-ключи, так и embed-токены через `EmbedToken` model.

**Billing:**
- `POST /api/v1/billing/create` — создать платёж (ЮKassa)
- `GET /api/v1/billing/status` — статус подписки

### 4.5 Безопасность

- API-ключи: UUID v4, хранятся в plain text (хешировать — TODO)
- Embed-токены: временные, 30-дневный TTL
- Анти-абьюз промпт для обычных пользователей: AI оценивает подозрительные запросы перед выполнением
- Блокировка по platformUserId + platform
- Данные изолированы по `userId` (MongoDB запросы всегда с `userId: req.user._id`)
- CORS настроен для `/api/v1/analyze` (публичный), остальные защищены
- 152-ФЗ: данные хранятся на российских серверах

### 6.1 Быстрый старт (5 минут)

1. **Регистрация** → `siberi.online` → «Начать бесплатно»
2. **Настройка AI** (`/settings`):
   - Заполните «Описание задач AI» — что ваш ассистент должен делать
   - Задайте имя бота (опционально)
3. **Добавьте данные** (`/data`):
   - Нажмите «Создать схему» или попросите AI: *«Создай схему для записей клиентов»*
   - Добавьте записи вручную или через импорт
4. **Подключите интеграцию** (`/integrations`):
   - Для Telegram: создайте бота через @BotFather → вставьте токен → «Подключить»
   - Для сайта: скопируйте один тег и вставьте перед `</body>`
5. **Готово** — ваш AI работает

### 6.2 Настройка AI (AISettings)

**Системный промпт** — главный инструмент. Примеры:

```
Ты — консультант магазина электроники "Технопарк".
Отвечай только на вопросы о товарах из базы данных.
Всегда предлагай альтернативы если товара нет в наличии.
Будь вежлив и конкретен. Не обсуждай конкурентов.
```

**Важно:** чем точнее промпт, тем лучше AI понимает свою задачу.

**AI-профили** позволяют создать несколько независимых конфигураций:
- Разные профили для разных Telegram-ботов
- Разные базы данных для каждого профиля
- Переключение профиля в настройках

### 6.3 Работа с данными

**Через интерфейс:**
- `/data` → выберите схему → «Добавить запись»

**Через чат (AI-команды):**
- *«Добавь нового клиента: Иван Петров, телефон 89001234567, источник Instagram»*
- *«Отметь заказ #42 как выполненный»*
- *«Удали запись о товаре Наушники Sony»*

**Откат изменений:**
- `/panel` → найдите нужный запрос → «Откатить»
- Откатывает ВСЕ изменения данных начиная с этого запроса

### 6.4 Управление доступом

В `/settings` → «Управление доступом»:

1. Добавьте пользователя: выберите платформу → введите ID → выберите роль
2. Для Telegram: ID = числовой chatId пользователя (можно узнать через @userinfobot)
3. Для веб-сайта: ID передаётся через `?userId=...` в URL виджета

**Роли:**
- **Создатель** — вы сами (полный доступ)
- **Администратор** — ваши сотрудники (настраиваемые права)
- **Пользователь** — ваши клиенты (базовые права)

### 6.5 Виджет на сайт

**Минимально:**
```html
<script src="https://siberi.online/siberi-widget.js?token=ВАШ_EMBED_ТОКЕН"></script>
```

**С управлением доступом:**
```html
<script src="https://siberi.online/siberi-widget.js?token=ВАШ_EMBED_ТОКЕН&userId=ID_ВАШЕГО_ПОЛЬЗОВАТЕЛЯ"></script>
```

Embed-токен берётся в `/integrations` → «Онлайн-консультант» → «Обновить токен».

## 7. ДОКУМЕНТАЦИЯ ДЛЯ РАЗРАБОТЧИКА (API)

### 7.1 Аутентификация

```http
Authorization: Bearer YOUR_API_KEY
```

API-ключ доступен в личном кабинете на странице «Интеграции».

### 7.2 Базовый запрос (асинхронный)

**Шаг 1: Отправить промпт**
```http
POST https://siberi.online/api/v1/analyze
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "prompt": "Покажи список всех клиентов",
  "platformUserId": "user_123",
  "platform": "web",
  "profileId": "OPTIONAL_PROFILE_ID"
}
```

**Ответ:**
```json
{ "success": true, "taskId": "uuid-v4" }
```

**Шаг 2: Получить результат (polling)**
```http
GET https://siberi.online/api/v1/result/{taskId}
Authorization: Bearer YOUR_API_KEY
```

**Ответ (pending):**
```json
{ "status": "pending" }
```

**Ответ (completed):**
```json
{
  "status": "completed",
  "result": "Вот список клиентов...",
  "attachments": ["data:image/png;base64,..."]
}
```

### 7.3 Параметр platformUserId

Передавайте `platformUserId` для работы системы ролей:
- Если ID совпадает с записью в «Управление доступом» → AI получает роль пользователя
- Если не передан → обычный пользователь (базовые права)

### 7.4 Работа с изображениями

```json
{
  "prompt": "Что изображено на этом фото?",
  "image": "data:image/jpeg;base64,/9j/4AAQ..."
}
```

### 7.5 JavaScript SDK

```html
<script src="https://siberi.online/siberi-sdk.js"></script>
<script>
  const api = SiberiAI({ apiKey: 'YOUR_API_KEY' });

  // Спросить AI
  const answer = await api.chat.send('Сколько заказов за сегодня?');

  // Работа с данными
  const { records } = await api.records.list('orders');
  await api.records.create('clients', { name: 'Иван', phone: '89001234567' });
</script>
```

### 7.6 Webhook-коллбэки

После каждого ответа AI отправляет POST на ваш сервер:
```json
{
  "source": "telegram",
  "prompt": "Запрос пользователя",
  "result": "Ответ AI",
  "attachments": [],
  "taskId": "uuid"
}
```
