# Веб-клиент Siberi AI

React + Vite: лендинг, кабинет, чат с ассистентом, данные пользователя, интеграции, студия ботов и админка.

```powershell
npm install
npm run dev          # http://127.0.0.1:5173, запросы /api проксируются на сервер :3000
npm run build:prod   # сборка + пререндер страниц для поисковиков (react-snap)
npm run lint
```

Сервер и общий запуск — в [README репозитория](../README.md).
